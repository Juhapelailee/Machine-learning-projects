These are small ML projects that were done during the DATA.ML.100 - course in Tampere University.

## Setup
Clone the repository:
```bash
git clone https://github.com/Juhapelailee/Machine-learning-projects.git
cd Machine-learning-projects
```
Before running any of the scripts in this repository, install the required packages:

```bash
pip install -r requirements.txt
```

If you don't have `pip` installed:

```bash
python -m ensurepip --default-pip
```
